# RetroStyle: Explorador de Modas del Pasado 👗📼

Este es un proyecto web creado con HTML y CSS que te permite explorar diferentes modas del pasado, desde los años 60 hasta los 2000. La página no solo te informa sobre cada estilo, sino que también ofrece enlaces o recomendaciones sobre dónde puedes conseguir prendas similares hoy en día.

## 🚀 Características

- Navegación sencilla y estética retro.
- Información sobre tendencias de distintas décadas.
- Imágenes representativas de cada época.
- Enlaces o sugerencias para comprar ropa de estilo vintage.

## 🛠️ Tecnologías utilizadas

- **HTML5** para la estructura del sitio.
- **CSS3** para el diseño y estilos visuales.
- (Opcional) Puedes mencionar si usaste algún framework como Bootstrap o alguna fuente de Google Fonts.

## 💡 Objetivo del proyecto

El objetivo de este sitio es celebrar y difundir la moda retro, ofreciendo una experiencia nostálgica e informativa, y ayudando a los usuarios a encontrar prendas similares en tiendas físicas o en línea.
